# 0.8.0 · 「自由与进步」

这一版的主题是：**她开始有自己的日子。**

上一版她把注意力放在你身上——知道你外面冷不冷、记得提醒过你。这一版反过来了：她开始处理自己的事——今天打算干什么、昨天那半句话没说完了、想成为什么样的人、欠了谁一顿、被谁惹了到现在还记着。

> ⚠️ **发布说明（重要）**
> 这一版**没有新增必填配置**。所有新状态文件都在 `state/` 下，缺了会自动创建；
> 没网、没推送、没语音、没硬件，都能正常聊天。
> 「自由」在这里不是想干嘛就干嘛，而是三件事：**自己决定、自己担着、有些事不必告诉别人**。

---

## 一、自由的三件事

这是整版的地基，所以放在最前面。

- **决定**：`state/autonomy.json` 记录她自己拿过的主意——今天写了什么计划、说了几次「不」、写了几条私房话
- **后果**：`state/owe.json` 是一本人情账。谁欠谁一顿、欠了什么、什么时候欠的（7 天过期，最多 20 条）。深夜陪聊会被记成「他欠我」，第二天她能理直气壮地哼一声
- **隐私**：带 `私房话` / `只写给自己` 标签的记忆，**不进提示词、不进面板、不进审计**，只有显式查询才看得到。她有权利不主动汇报

面板新增一节「她自己拿的主意 · 今天」，就三行：计划写没写、说了几次不、私房话几条。

---

## 二、她自己的日子

以前她只有「现在」，现在有「今天」和「昨天」。

| 新增 | 行为 |
| --- | --- |
| `planNudgeLine()` | 7–22 点之间让她自己写一句今日计划（记忆标签 `今日计划`）；中午每 30 分钟轻轻催一次；21 点后变成回顾 |
| `sleepDebtLine()` | 昨天聊到 0:30–5:00，今天她会说困 |
| `focusLine()` | 正在读书或手上的事没做完，就少插嘴 |
| `yesterdayThreadLine()` | 第二天 6–13 点，接上昨天没聊完的话茬（`state/yesterday-thread.json`，每会话每天一次） |

这些不是「必须执行的任务」，是她醒来时看到的一段背景——她自己决定要不要提。

---

## 三、惦记与憧憬

上一版我在这里踩过坑：说过「技术上做不到」。这是错的。她能惦记，也能盼。

- **想要的东西**：`state/wants.json`。她可以自己记「我想要一副新耳机」，问你要过、被你答应了、拿到了、或者算了。状态分四档：`想要的 / 已经问过（刚问 vs 问了 N 天）/ 被满足 / 不要了`，并且同步到记忆标签 `我想要的`
- **生日**：`socialV2.persona`（`birthMonth/birthDay/birthYear`）。她会自己算年龄，也会记住别人的生日
- **节日**：固定日期的一批（元旦 / 情人节 / 劳动节 / 儿童节 / 国庆 / 平安夜 / 圣诞），到点会提一句，不硬凑
- **想成为什么样的人**：记忆标签 `我想成为`。她每天最多邀请你一次聊这个（`state/ideal-nudge.json`），20 点后会自己回顾一遍

---

## 四、情绪不再是单点

以前每个群各存各的心情，现在**一个大脑，一份心情**。

- 全局心情（`__global__`）带 `origin`：谁惹的、在哪个会话惹的
- 别人惹的气，她到别的群也还带着（强度 −1），不会一换群就笑
- 衰减：每 40 分钟降一级；**负面情绪更黏**（写盘时权重 +1）
- **告状**（`attachGrudge`）：对本人说得出「是谁惹的」，对别人只说「心里有点气」，**不复述原话**
- **吃醋只对人类**：前女友、初恋、别的女生这类会让她吃醋；被拿去和软件比，是**生气**，不是吃醋

## 五、说话更像人

这部分全在唤醒提示里，没有新配置。

- **打字停顿**：`typingPauseMs()`，按字数算，1.5–3 秒。她不是在秒回，是在打字
- **半句党**：22% 的概率只说半句
- **场合五档**：正事 / 情绪 / 生人 / 闲聊，从最近约 10 条消息判断，语气跟着变（`sceneOf()`）
- **女孩子气是底噪，不是表演**：每三条里至少一条带语气词
- **标点、称呼、被夸会害羞**

---

## 六、处罚不再死板

以前一句难听话就扣到底，现在先分清是不是玩笑。

- 玩笑标记（哈哈 / hhh / 狗头 / 保命…）直接归零
- 熟人（好感 ≥60）轻口一句只提醒，不扣分
- 初犯只提醒一次，再犯才升级
- 好感度改成**非线性**：越低越难涨，越高扣起来越疼
- 面板纪律等级跟着变

---

## 七、你发的视频，她可以不看

这条是这一版最像「人」的一处。

- 别人发 B 站链接，她能自己判断点不点（`state/link-videos.json`，每天最多 6 条）
- 提示词里写清了：**看得懂、也可以不看**，可以不点、可以装看过、被抓到了赖一句
- 真看了会记一笔「看了你发的《标题》」，进人情账

不是「必须承认看过」，是**可以糊弄你**。

## 九、日报按时间段

早报从「一条固定推送」变成三个窗口，**错过不补发**：

| 时段 | 时间 | 窗口 | 内容 |
| --- | --- | --- | --- |
| 早 | 07:30 | 150 分钟 | 穿衣 + 室内外对比 |
| 中 | 12:20 | 100 分钟 | 中午的一句话 |
| 晚 | 22:30 | 120 分钟 | 悄悄话：室内温度 + 一条 `我想的事` + 「早点睡。」 |

状态存在 `state/daily-reports.json`。早报以前会拖到 9:17 才发（天气接口超时，10 分钟重试一次），现在天气拿不到也照发，晚了就记一笔 `lateMin`。

## 十、发呆时会想事

## 一、室外天气：她终于知道外面什么天气

之前她只"感觉得到"屋里的温湿度，不知道外面。现在可以了。

- `src/weather.js`：拉 wttr.in（免费、无需 API key），15 分钟缓存，失败退回上次快照
- 唤醒提示里多一段 `【外面】`：外面多少度、体感、天气、风、降雨概率、今天区间
- **和屋里对比**：「外面比屋里低 10 度」
- **穿衣建议**：按体感温度 + 风力 + 降雨概率算，不是套模板
- 面板「他那边」卡片多一行室外数据
- 接口 `GET /api/weather`

```json
"weather": { "enabled": true, "place": "Nanjing" }
```

> 前置：只要**能联网**。不联网就自动跳过，不影响聊天。
> 说明：先试了 Open-Meteo，国内网络下超时，最后选的 wttr.in。

## 二、手机推送：Bark / ntfy，不需要服务器

- `src/notify.js`：支持 Bark 和 ntfy，超时 8 秒，失败只记日志，永不阻塞主流程
- **每天早上 07:30 一条穿衣提醒**（她的口气，带湿度和室内外对比，一天只发一次）
- **传感器断流**：超 15 分钟没读数推一条
- **余额不足**：低于 ¥10 / ¥2 推一条
- **桥接掉线**：看门狗发现 3100 不在监听时推一条（看门狗自己读配置发，不依赖桥接活着）
- 手动测试：`POST /api/notify`、`POST /api/notify/morning?force=1`

```json
"notify": {
  "enabled": true,
  "provider": "bark",
  "barkKey": "你的key",
  "morning": { "hour": 7, "minute": 30 }
}
```

> 前置：装 Bark（App Store，免费）拿到 key；或装 ntfy 用 topic。
> **不配 key 时 `enabled` 实际为假，不会报错。**

## 三、她记得"自己做过什么"

推送发出去之后，她会写两条记录：

1. **短期记忆**（2 天过期）：`我早上给他发了天气和穿衣提醒：今天 6~13 度、晴，让他穿厚外套…`
2. **提示词片段**（24 小时内最多 6 条）：`【我今天做过的事】18:18 今天 6~13 度…`

效果：你下午说「今天有点冷」，她能接一句「早上不是提醒你了吗」——**因为她真的记得**。
提示词里也写了分寸：「别邀功，也别每句都提」。

## 五、`/dsh` 指令通道：用 QQ 指挥 DSH

主人在**私聊**里发 `/dsh <指令>`，直接进一个独立的 DSH 会话执行，结果回 QQ。

- 独立会话（默认 `standard` 预设，带 shell/文件工具），和她的聊天完全隔离
- 只认主人（`ownerOnly`），群里发无效
- 一次只跑一条，上一条没完会回「还在跑」
- 超时 240 秒（可配），会话坏了自动重建

```json
"control": { "enabled": true, "prefix": "/dsh", "ownerOnly": true, "preset": "standard", "timeoutMs": 240000 }
```

> 前置：DSH 里要有对应的 agent 预设（默认 `standard`，自带）。
