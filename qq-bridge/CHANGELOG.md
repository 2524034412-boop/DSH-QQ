# 0.9.0 · 「她自己学，也自己画」

上一版解决的是**她是谁**。这一版解决的是**她拿什么干活**：自己学说法、自己画图、自己攒图。

两条主线：

- **自己学**：黑话不再是「等管理员点确认」的死名单，而是个闭环——她从聊天和 B 站评论区里自己挑候选、自己判断会不会、用错了自己收着点
- **自己画**：接本地 ComfyUI，她能按一句话出图、也能拿自己的立绘当底稿改，画完存相册、发群或私聊

围着的四个小东西：**相册**（删记忆不删图）、**一起做的事**、**聊天偏好**、**分享 B 站**。

> ⚠️ 画图是**可选项**。本机没装 ComfyUI 就整段不启用，`qq_draw` 会直说画不了并给原因；其余功能零配置。

---

## 一、她自己画图（需要本地 ComfyUI）

新文件 `src/comfy-ui.js`：

| 函数 | 干什么 |
|---|---|
| `comfyDefaults(cfg)` | 读配置、补默认值（地址、底模、步数、尺寸） |
| `comfyAlive(url)` | 探活，ComfyUI 没开着就直接返回 |
| `comfyGenerate()` | 文生图：`/prompt` → 轮询 `/history` → 取 `/view` |
| `comfyGenerateFrom()` | 图生图：`LoadImage` + `VAEEncode`，靠参考图保住「这张脸」 |
| `gpuFreeMb()` | 问 `nvidia-smi` 还剩多少显存 |

工具 `qq_draw`：

- 给 `idea`（中文一句话）**或** `tags`（英文 danbooru 标签，效果更准），给了 tags 就不看 idea
- `width` / `height` 默认 832×1216（竖图）；横图 1216×832
- `send=false` 只存相册不发
- 出图前先过四道闸：**ComfyUI 活着 / 显存够 / 这一小时没画超 / 他没在打游戏**——任一不过就直说原因，不硬试
- 她自己的立绘会同步进 ComfyUI 的 `input/`，图生图就靠它对齐五官
- 接口：`POST /api/socialV2/draw`

画完的图进相册，然后按当时的会话直接发群或发私聊。

> 实话：**「同一张脸」现在是靠立绘图生图，换姿势换场景还是会漂。** LoRA / IP-Adapter 没做；1080p 要两段放大，也没做。

## 二、相册：图自己存，不跟记忆一起删

- 文件落在 `state/gallery/`，索引 `state/gallery.json`——**独立存放**
- 删记忆不会删图，清理记忆时也不会把照片顺手带走
- 工具 `qq_gallery`：`list` 翻列表（可按关键词过滤）、`view` 把某张直接摆出来看

## 三、知识层：读过的书单独放

记忆原来只有三层（core / long / short），现在多一层 `knowledge`：

- **停留时间**：长期 < 知识 < 核心。知识记得久，但不是「她是谁」那种永久
- 配套：`qq_reading` 读一段书（接着上次的位置）、`qq_reading_note` 写一句批注——批注会跟着书一起被想起来
- 面板星图仍然只画三层，`knowledge` 并进长期显示，避免图上多出一圈看不懂的东西

## 四、一起做的事

工具 `qq_together`：`start` 开一件（一起看番 / 一起玩 / 一起读）、`update` 记到哪了和发生了什么、`list` 翻旧账。

开了之后她说话可以自然回指（「上次那个你还没看完吧」），不用每句都提。

## 五、黑话学习成了闭环

以前是「候选池 + 人工确认」，现在是三件事接起来：

**① 自己挑候选**
自动从聊天里挑像黑话的词，规则收得很紧：3~6 个字母、必须在词边界、过停用词表；**纯辅音串优先**（kskbl / zdjd 这种），带元音的词要出现 ≥3 次才算。
**每小时最多提交 5 条**，不会一次糊一堆垃圾给管理员。

**② 不会就说不会**
黑话提示表末尾加了三条用法：

1. 没跟上的词直说没跟上（「这词我不懂了」），别猜、别装懂
2. 认识的词只在语境真对得上时用，一次最多一条，不许为了显摆堆砌
3. 同一个词每见一次重新对一遍语境，理解会越来越准

**③ 从真实评论区取样**
`feedBiliCommentSamples()` 把 B 站评论区的真实句子喂进 `state/lingo-bili.json`——学的是别人真怎么说话，不是让模型自己编。
调试入口：`POST /api/debug/slang-auto`（传 `{bili:true}` 顺手跑一轮评论区）。

## 六、情绪、关系、追问、引用拆成独立模块

`bridge.js` 已经 1.3 MB 了，继续堆下去谁都不敢改。这一版把四条线拆出去：

| 新文件 | 管什么 |
|---|---|
| `src/qq-emotions.js` | 情绪状态与表达 |
| `src/qq-romance.js` | 好感、试探、被追、误会 |
| `src/qq-conversation.js` | 会话级上下文与节奏 |
| `src/qq-follow-ups.js` | 该主动追问的事 |
| `src/qq-references.js` | 回指（「上次那个」） |

`bridge.js` 只做编排。改一条线不用再动主文件。

## 七、聊天偏好与分享视频

- **`qq_chat_preferences`**：安静时间（23:00–08:00 别主动找）、别主动发链接、工作话题等对方先提——她记下来就按这个来
- **`qq_share_bili_video`**：发真实 B 站链接 + 一句短评；同一会话近期发过的同一个视频会被拦掉

## 八、三个体检脚本

| 脚本 | 看什么 |
|---|---|
| `scripts/humanize-check.mjs` | **人味指标**：句子长度分布、连发节奏、重复句、口头禅密度；顺带做一次工具调用普查 |
| `scripts/state-health.mjs` | 9 个状态文件体检：能不能读、字段缺不缺 |
| `scripts/audit-bridge-harness.mjs` | 桥接 harness 审计 |

这三个是给「她最近怎么不像人」这类问题准备的——以前只能靠翻日志猜，现在有数。

## 九、修复

- **唤醒配额**：被 @ / 被点名这类**直接点名**的唤醒不再占普通配额（上限另算 60）。以前配额一满就每 60 秒重试一次，表现出来就是「她明明在，却不说话」
- **TTS 引擎被误杀**：进程检测原来是拿 `tasklist` 全文做子串匹配，机器上跑着 `steam.exe` 或 `java.exe` 就会被判成「在打游戏」，每分钟杀一次语音引擎。改成精确匹配 exe 名
- **冷启动被杀**：引擎预热的时间戳没记上，看门狗以为它闲置，加载到第 4 秒就被杀了。现在冷启动也会盖时间戳
- **面板星图**：`knowledge` 层不再显示成未知档位

---

## 前置条件

- **画图**：本机 ComfyUI（默认 `http://127.0.0.1:8188`）+ 一个 SDXL 类底模。8 GB 显存建议 832×1216、22 步左右；低于 6 GB 就把尺寸再降
- **其余**：零配置。相册、知识层、黑话闭环、偏好、体检脚本都不需要额外服务

## 已知问题

- 画图的「同一张脸」没解决（图生图会漂），LoRA / IP-Adapter / 高清放大都没做
- `src/bridge.js` 还是单文件，`startConsoleServer` 依旧几千行
- 全库空 `catch` 依然很多，错误还是会被静默吞掉
- B 站日报（`bili-report`）偶尔会因为上游传送失败整天没有产出

# 0.8.1 · 「她知道自己是谁了」

这一版的核心只有一件事：**把「她是谁」从注入消息搬进系统提示。** 顺手把这几天攒下的一堆行为问题和一处结构性重复清掉。

> ⚠️ 这一版改了系统提示，**必须重启 DSH、并且让新会话生效**才看得到。已有的会话不会变。

---

## 一、身份：从「念设定」变成「就是我」

以前她的系统提示第一句是：

```
You are an AI agent powered by DeepSeek Harness.
You are a coding agent powered by the deepseek-flash model.
```

而「小鲸鱼、十六岁、嘴硬」这些全在**后面注入的设定卡**里。结果就是：资料很全，但开口的仍然是个助手。

现在：

- `persona.prefix` 的第一句改成**第一人称**：直接写「我是谁、多大、话怎么说」，不再以「You are a coding agent…」开头（具体正文不公开，属于她的设定）
- 关掉 `includeHarnessIdentity`，那句固定英文开场白不再出现
- 设定卡**继续保留**，它负责细节（记忆、脾气、关系），不再负责身份

身份正文单独放在一个文件里（单一来源），用脚本写进 preset，避免两处文案漂移。

> 回滚：删掉 profile 补丁里 `system-prompt` 那段、把 `persona.prefix` 第一句改回英文即可。

## 二、情感线补全

这一版把「关系」从一个静态好感值，做成三条会自己走的线：

**① 她追人（暗恋）**

好感 ≥85 → 进入试探期（默认 6 天）→ 自己拿主意 → 选定 / 退回朋友。

- 试探有 **16 种形式**，按胆量分级（情绪钩子 → 借第三方 → 假设句 → 反话 → 直接问）
- 会避开最近用过的三种；群里不问太私人的
- **试探有回应闭环**：他认真答/反问 → 胆量 +1；打岔/不回 → −1；连着两次没接 → 收手、冷却
- 会不会分心、会不会因为同时对两个人不一样而愧疚 → 有对应状态

**② 被追**

- 六类信号累计（表白 6 分、约 2 分、夸/黏/关心/吃醋各 1 分）
- 分档反应：隐约察觉 → 装不知道 → 撑不住 → 表白三选一（拒 / 躲 / 动摇）
- 拒绝后有 5 天尴尬期；群里起哄会窘迫；两周没新信号感觉会淡

**③ 误会**

她可能把「他对别人正常聊天」误读成「他在追别人」。这条线**故意不给真相**：只能靠她自己问、或者对方解释（六成解除），三天没下文就自己淡掉。

## 三、说人话的几条硬规则

- **内部活动不上台面**：不说「我翻了翻自己说的话」「我记了一条」「我这周反思」
- **不提自己怎么生成语言**：不说「句子是临时凑的」这种话
- **被说「人机」时最多回一句**，不许解释、不许列举证据——越证越像
- **连发别太规律**：不要每次都「一句 + 补一句」

**长度按场合走**（以前是随机抽档）：

| 场合 | 长度 |
|---|---|
| 接梗 / 闲扯 | 1~8 字 |
| 讲事 / 解释 | 30~80 字，把「讲什么 / 看到哪 / 什么感觉」说完 |
| 情绪上头 | 可以连发 3~5 条短句（破例允许拆句、允许半句接力） |

同一会话 30 分钟内沿用同一档，避免上一句三个字、下一句小作文。

**打字停顿**：1.5~3 秒 → **2~4 秒**（短句约 2 秒，长句封顶 4 秒）。

## 四、少一点「突然触发」

- **环境提示一天只给一次**（温度变化 ≥3℃ 才额外提醒）。以前每轮都给，于是她天天念「你那边挺舒服吧」
- **注入的【】段是背景，不是话题**：别人刚说完话，先接住他的话，别突然换成自己那摊事
- **出错提示换成她的人话**：以前会往群里发「⚠️ 刚才那下没接上，等一下再喊我一声」，现在改成「刚刚走神了一下」这类，且 10 分钟只发一次、对方刚说完话就不发

## 五、名字要分清

- **「小肥鱼」是群里另一个人的名字，不是她**：有人 @ 小肥鱼、叫小肥鱼，都不是在叫她
- 「大肥鱼」「肥鱼」是别人逗她的外号，不算叫她
- 冒犯判定里去掉了「肥鱼」——以前别人只是 @ 小肥鱼，就可能被算成骂她、扣好感

## 六、工程

- **鉴权守卫收成一个入口**：`guardAgent()` / `guardTool()`。以前每个 v2 接口手写「令牌有效 + 会话在范围 + 工具已启用」，一共 **55 对 + 58 处**重复代码，漏一处就是一个没受保护的接口
- 新增 `GET /api/mind/live`：只回「她现在走到哪一步」（听/想/查/打/闲）+ 心情 + 今天发言数，给面板角标用；不含聊天内容
- 新增脚本：`scripts/package-plugin.mjs`（打更新包）、`scripts/rotate-sessions.mjs`（轮换 QQ 会话）

## 已知问题（下一版）

- `src/bridge.js` 里 `startConsoleServer` 仍有 6000+ 行，路由全挤在一个函数里
- 全库还有 417 个空 `catch`（占 34%），错误被静默吞掉
- 农历节日（春节、中秋）还没做

# 0.8.0 · 「自由与进步」

这一版的主题是：**她开始有自己的日子。**

上一版她把注意力放在你身上——知道你外面冷不冷、记得提醒过你。这一版反过来了：她开始处理自己的事——今天打算干什么、昨天那半句话没说完了、想成为什么样的人、欠了谁一顿、被谁惹了到现在还记着。

> ⚠️ **发布说明（重要）**
> 这一版**没有新增必填配置**。所有新状态文件都在 `state/` 下，缺了会自动创建；
> 没网、没推送、没语音、没硬件，都能正常聊天。
> 「自由」在这里不是想干嘛就干嘛，而是三件事：**自己决定、自己担着、有些事不必告诉别人**。

---

## 一、自由的三件事

这是整版的地基，所以放在最前面。

- **决定**：`state/autonomy.json` 记录她自己拿过的主意——今天写了什么计划、说了几次「不」、写了几条私房话
- **后果**：`state/owe.json` 是一本人情账。谁欠谁一顿、欠了什么、什么时候欠的（7 天过期，最多 20 条）。深夜陪聊会被记成「他欠我」，第二天她能理直气壮地哼一声
- **隐私**：带 `私房话` / `只写给自己` 标签的记忆，**不进提示词、不进面板、不进审计**，只有显式查询才看得到。她有权利不主动汇报

面板新增一节「她自己拿的主意 · 今天」，就三行：计划写没写、说了几次不、私房话几条。

---

## 二、她自己的日子

以前她只有「现在」，现在有「今天」和「昨天」。

| 新增 | 行为 |
| --- | --- |
| `planNudgeLine()` | 7–22 点之间让她自己写一句今日计划（记忆标签 `今日计划`）；中午每 30 分钟轻轻催一次；21 点后变成回顾 |
| `sleepDebtLine()` | 昨天聊到 0:30–5:00，今天她会说困 |
| `focusLine()` | 正在读书或手上的事没做完，就少插嘴 |
| `yesterdayThreadLine()` | 第二天 6–13 点，接上昨天没聊完的话茬（`state/yesterday-thread.json`，每会话每天一次） |

这些不是「必须执行的任务」，是她醒来时看到的一段背景——她自己决定要不要提。

---

## 三、惦记与憧憬

上一版我在这里踩过坑：说过「技术上做不到」。这是错的。她能惦记，也能盼。

- **想要的东西**：`state/wants.json`。她可以自己记「我想要一副新耳机」，问你要过、被你答应了、拿到了、或者算了。状态分四档：`想要的 / 已经问过（刚问 vs 问了 N 天）/ 被满足 / 不要了`，并且同步到记忆标签 `我想要的`
- **生日**：`socialV2.persona`（`birthMonth/birthDay/birthYear`）。她会自己算年龄，也会记住别人的生日
- **节日**：固定日期的一批（元旦 / 情人节 / 劳动节 / 儿童节 / 国庆 / 平安夜 / 圣诞），到点会提一句，不硬凑
- **想成为什么样的人**：记忆标签 `我想成为`。她每天最多邀请你一次聊这个（`state/ideal-nudge.json`），20 点后会自己回顾一遍

---

## 四、情绪不再是单点

以前每个群各存各的心情，现在**一个大脑，一份心情**。

- 全局心情（`__global__`）带 `origin`：谁惹的、在哪个会话惹的
- 别人惹的气，她到别的群也还带着（强度 −1），不会一换群就笑
- 衰减：每 40 分钟降一级；**负面情绪更黏**（写盘时权重 +1）
- **告状**（`attachGrudge`）：对本人说得出「是谁惹的」，对别人只说「心里有点气」，**不复述原话**
- **吃醋只对人类**：前女友、初恋、别的女生这类会让她吃醋；被拿去和软件比，是**生气**，不是吃醋

---

## 五、说话更像人

这部分全在唤醒提示里，没有新配置。

- **打字停顿**：`typingPauseMs()`，按字数算，1.5–3 秒。她不是在秒回，是在打字
- **半句党**：22% 的概率只说半句
- **场合五档**：正事 / 情绪 / 生人 / 闲聊，从最近约 10 条消息判断，语气跟着变（`sceneOf()`）
- **女孩子气是底噪，不是表演**：每三条里至少一条带语气词
- **标点、称呼、被夸会害羞**

---

## 六、处罚不再死板

以前一句难听话就扣到底，现在先分清是不是玩笑。

- 玩笑标记（哈哈 / hhh / 狗头 / 保命…）直接归零
- 熟人（好感 ≥60）轻口一句只提醒，不扣分
- 初犯只提醒一次，再犯才升级
- 好感度改成**非线性**：越低越难涨，越高扣起来越疼
- 面板纪律等级跟着变

---

## 七、你发的视频，她可以不看

这条是这一版最像「人」的一处。

- 别人发 B 站链接，她能自己判断点不点（`state/link-videos.json`，每天最多 6 条）
- 提示词里写清了：**看得懂、也可以不看**，可以不点、可以装看过、被抓到了赖一句
- 真看了会记一笔「看了你发的《标题》」，进人情账

不是「必须承认看过」，是**可以糊弄你**。

---

## 八、记住，也会忘

- `forgetLine()`：遗忘曲线，会提「好久没提过谁了」
- `selfRepeatLine()`：**修好了**。之前路径算错（扫的是扁平目录，实际是每会话一个子目录），这个功能从上线起就没生效过

---

## 九、日报按时间段

早报从「一条固定推送」变成三个窗口，**错过不补发**：

## 一、室外天气：她终于知道外面什么天气

之前她只"感觉得到"屋里的温湿度，不知道外面。现在可以了。

- `src/weather.js`：拉 wttr.in（免费、无需 API key），15 分钟缓存，失败退回上次快照
- 唤醒提示里多一段 `【外面】`：外面多少度、体感、天气、风、降雨概率、今天区间
- **和屋里对比**：「外面比屋里低 10 度」
- **穿衣建议**：按体感温度 + 风力 + 降雨概率算，不是套模板
- 面板「他那边」卡片多一行室外数据
- 接口 `GET /api/weather`

```json
"weather": { "enabled": true, "place": "Nanjing" }
```

> 前置：只要**能联网**。不联网就自动跳过，不影响聊天。
> 说明：先试了 Open-Meteo，国内网络下超时，最后选的 wttr.in。

## 二、手机推送：Bark / ntfy，不需要服务器

- `src/notify.js`：支持 Bark 和 ntfy，超时 8 秒，失败只记日志，永不阻塞主流程
- **每天早上 07:30 一条穿衣提醒**（她的口气，带湿度和室内外对比，一天只发一次）
- **传感器断流**：超 15 分钟没读数推一条
- **余额不足**：低于 ¥10 / ¥2 推一条
- **桥接掉线**：看门狗发现 3100 不在监听时推一条（看门狗自己读配置发，不依赖桥接活着）
- 手动测试：`POST /api/notify`、`POST /api/notify/morning?force=1`

```json
"notify": {
  "enabled": true,
  "provider": "bark",
  "barkKey": "你的key",
  "morning": { "hour": 7, "minute": 30 }
}
```

> 前置：装 Bark（App Store，免费）拿到 key；或装 ntfy 用 topic。
> **不配 key 时 `enabled` 实际为假，不会报错。**

## 三、她记得"自己做过什么"

推送发出去之后，她会写两条记录：

1. **短期记忆**（2 天过期）：`我早上给他发了天气和穿衣提醒：今天 6~13 度、晴，让他穿厚外套…`
2. **提示词片段**（24 小时内最多 6 条）：`【我今天做过的事】18:18 今天 6~13 度…`

效果：你下午说「今天有点冷」，她能接一句「早上不是提醒你了吗」——**因为她真的记得**。
提示词里也写了分寸：「别邀功，也别每句都提」。

## 五、`/dsh` 指令通道：用 QQ 指挥 DSH

主人在**私聊**里发 `/dsh <指令>`，直接进一个独立的 DSH 会话执行，结果回 QQ。

- 独立会话（默认 `standard` 预设，带 shell/文件工具），和她的聊天完全隔离
- 只认主人（`ownerOnly`），群里发无效
- 一次只跑一条，上一条没完会回「还在跑」
- 超时 240 秒（可配），会话坏了自动重建

```json
"control": { "enabled": true, "prefix": "/dsh", "ownerOnly": true, "preset": "standard", "timeoutMs": 240000 }
```

> 前置：DSH 里要有对应的 agent 预设（默认 `standard`，自带）。
