# 0.7.0 · 「她会提醒你，也记得提醒过」

这一版主题是**从"能聊"变成"会照顾人"**：她开始知道外面冷不冷、会主动推你一条穿衣提醒、
会记得自己提醒过你，还会顺手把重复的记忆整理掉。同时补了一层"出问题能自己查"的工程能力。

> ⚠️ **发布说明（重要）**：这一版新增的东西**大多是可选的**。
> 没硬件、没推送、没开控制通道，都能正常聊天——所有新功能默认关闭或自动降级，
> 详见最后一节「前置条件」。

---

## 一、室外天气：她终于知道外面什么天气

之前她只"感觉得到"屋里的温湿度，不知道外面。现在可以了。

- `src/weather.js`：拉 wttr.in（免费、无需 API key），15 分钟缓存，失败退回上次快照
- 唤醒提示里多一段 `【外面】`：外面多少度、体感、天气、风、降雨概率、今天区间
- **和屋里对比**：「外面比屋里低 10 度」
- **穿衣建议**：按体感温度 + 风力 + 降雨概率算，不是套模板
- 面板「他那边」卡片多一行室外数据
- 接口 `GET /api/weather`

```json
"weather": { "enabled": true, "place": "Nanjing" }
```

> 前置：只要**能联网**。不联网就自动跳过，不影响聊天。
> 说明：先试了 Open-Meteo，国内网络下超时，最后选的 wttr.in。

## 二、手机推送：Bark / ntfy，不需要服务器

- `src/notify.js`：支持 Bark 和 ntfy，超时 8 秒，失败只记日志，永不阻塞主流程
- **每天早上 07:30 一条穿衣提醒**（她的口气，带湿度和室内外对比，一天只发一次）
- **传感器断流**：超 15 分钟没读数推一条
- **余额不足**：低于 ¥10 / ¥2 推一条
- **桥接掉线**：看门狗发现 3100 不在监听时推一条（看门狗自己读配置发，不依赖桥接活着）
- 手动测试：`POST /api/notify`、`POST /api/notify/morning?force=1`

```json
"notify": {
  "enabled": true,
  "provider": "bark",
  "barkKey": "你的key",
  "morning": { "hour": 7, "minute": 30 }
}
```

> 前置：装 Bark（App Store，免费）拿到 key；或装 ntfy 用 topic。
> **不配 key 时 `enabled` 实际为假，不会报错。**

## 三、她记得"自己做过什么"

推送发出去之后，她会写两条记录：

1. **短期记忆**（2 天过期）：`我早上给他发了天气和穿衣提醒：今天 6~13 度、晴，让他穿厚外套…`
2. **提示词片段**（24 小时内最多 6 条）：`【我今天做过的事】18:18 今天 6~13 度…`

效果：你下午说「今天有点冷」，她能接一句「早上不是提醒你了吗」——**因为她真的记得**。
提示词里也写了分寸：「别邀功，也别每句都提」。

## 四、记忆自动整理

- `src/memory-consolidate.js`：文本相似度 ≥62% 合并、短期被长期吸收、超 400 条丢最旧短期
- 每天**凌晨 4 点后**第一次检查时跑一次，启动时也补跑
- 手动：`node scripts/consolidate-memory.mjs [--apply]`
- 实测：222 → 216 条（合并 6 组，其中 1 组是完全重复）

## 五、`/dsh` 指令通道：用 QQ 指挥 DSH

主人在**私聊**里发 `/dsh <指令>`，直接进一个独立的 DSH 会话执行，结果回 QQ。

- 独立会话（默认 `standard` 预设，带 shell/文件工具），和她的聊天完全隔离
- 只认主人（`ownerOnly`），群里发无效
- 一次只跑一条，上一条没完会回「还在跑」
- 超时 240 秒（可配），会话坏了自动重建

```json
"control": { "enabled": true, "prefix": "/dsh", "ownerOnly": true, "preset": "standard", "timeoutMs": 240000 }
```

> 前置：DSH 里要有对应的 agent 预设（默认 `standard`，自带）。

| 改动 | 说明 |
|---|---|
| **反 AI 味黑名单** | 点名禁用「这话我认 / 这笔账我记着 / 我听着你往下讲 / 你自己信吗 / 睡吧我守着」这类"端着的深刻" |

## 九、前置条件（新用户请先看这里）

### 不需要任何前置，装上就能用

- 和她聊天、记忆、好感、情绪、群聊、控制面板、`/dsh` 指令通道

### 需要联网（不联网自动跳过，不报错）

- 室外天气、穿衣提醒

### 需要手机 App（不配就不发，不报错）

- 推送：Bark / ntfy

### 需要硬件（默认关闭，配了才启用）

| 硬件 | 用在哪 | 怎么开 |
|---|---|---|
| ESP32 + SHT31 | 室内温湿度 | `environment.enabled: true` |
| HC-SR501 | 有没有人在动 | 同上（同一块板） |
| GC9A01 圆屏 | 显示温湿度 + 她的小表情 | 烧 `esp32-sht30-display` 固件 |

**没有硬件完全不影响聊天**：`environment.enabled` 默认 `false`，
提示词里不会出现任何传感器内容，也不会启动 3101 端口。

### 可选：定时任务（不建也能用）

- 每周日说话体检、记忆整理、看门狗、账本轮转——都不建的话功能照常，只是不自动跑

## 十、升级注意

1. `config.example.json` 新增四段：`environment`（**默认关**）、`weather`、`notify`（**默认关**）、`control`
