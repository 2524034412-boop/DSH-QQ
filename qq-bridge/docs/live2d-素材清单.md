# Live2D 化素材清单（给 TapNow 出图用）

目标：用一套分层部件，做出「转头、眨眼、口型、尾巴摆动、表情混合」的效果。
**最关键的不是画得多好，而是所有部件在同一个坐标系里对齐。**

---

## 一、总的铁律

| 项 | 要求 |
|---|---|
| 画布 | **2048 × 3072**（竖 2:3），所有部件同一尺寸、同一位置 |
| 背景 | **纯绿色 #00FF00**（我会色键抠除），不要渐变、不要阴影、不要地面 |
| 格式 | PNG 无损；4K 出图后下采样到 2048 再交给我 |
| 光源 | 统一左上前方柔光，高光不过曝——**所有部件必须同一光照**，否则合成时脸会一块亮一块暗 |
| 重叠 | 每个部件比"实际可见区域"多画 2~3% 边（我要留变形余量，否则一转就露缝） |
| 视角 | 正面偏 15°，眼睛清楚，身高构图：膝上 3/4 身 |
| 一致性 | 同一种子 + 同一描述前缀，**每次只改一个部件** |

**生成流程（有局部重绘就走这条）**

```
1. 先用完整描述生成"参考立绘"，确定构图、光、比例，固定种子
2. 之后的每个部件：以参考立绘为底，用遮罩只重绘目标区域
3. 每件单独导出 PNG，画布尺寸和位置完全不变
```

## 四、我这边怎么用

```
1. 色键抠图 → 透明 PNG，边缘去绿边（decontaminate）
2. 自动对齐：以 face 的包围盒为基准，其余部件按质心/特征点配准
3. 生成 manifest.json：每件的 pivot（轴心）、depth（前后）、group（头/身/尾）
4. 引擎按参数驱动：
   - angleX/Y/Z   转头 —— 按 depth 做视差偏移 + 轻微横向压缩
   - eyeOpen      眨眼 —— 眼睑层下移
   - mouthOpen    说话 —— 三个口型交叉淡入
   - blush        害羞 —— 透明度
   - tailSway     尾巴 —— 弹簧链，每段延迟传递
   - breath       呼吸 —— 整体 1±0.8% 缩放
5. 接桥接状态：mood → 表情权重、TTS 播放 → 口型、鼠标 → 转头
```

## 五、验收标准

- [ ] 抠像后边缘无绿边、无白边
- [ ] 眨眼时眼睑覆盖完整，不露眼白
- [ ] 转头 ±15° 时，刘海/侧发/脸的层次不穿帮
- [ ] 说话时嘴型在闭嘴/啊/哦之间平滑过渡
- [ ] 60fps（1080p 下）
