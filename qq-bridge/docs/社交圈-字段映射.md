# 社交圈关系图 · 字段映射与调参

入口：记忆星图页（`/memory`）右上角 **星图 / 社交圈** 切换。
实现：`src/relation-graph.js`（纯函数） + `src/social-graph-view.js`（渲染） + `bridge.js` 里一个只读接口。

## 数据来源（全部只读）

| 文件 | 取什么 |
|---|---|
| `state/affinity.json` | `people[uid]` 的 `score` / `love` / `loyalty` / `lastAt` / `count` / `name` / `lastConv` |
| `state/impressions.json` | `people[uid]` 的 `text` / `sentiment` / `traits` |
| `state/discipline.json` | `users["group:NNN|uid"]` 的 `level` / `ignoreUntil` |
| `state/group-stats.json` | `group:NNN` 的 `speaks` / `msgs` / `joys` / `bonus` |
| `state/transcripts/group_*/ *.jsonl` | 每行的 `u` → 统计 uid 出现在哪些群 |

群归属：优先用聊天记录统计（近 30~40 天出现在哪些群），没有记录的退回 `affinity.lastConv`。

## 视觉编码

| 维度 | 编码 | 公式 / 位置 |
|---|---|---|
| 好感 `score` | 离中心距离 | `distanceFor()`：`0.22 + 0.78·(1-score/100)^0.85` |
| 喜爱 `love` | 光晕强度与暖色 | 光晕半径 `base·(1.6+1.6·love/100)`；`love>0` 时用暖色 `rgba(255,224,180)` |
| 忠诚 `loyalty` | 连线粗细 | `1 + loyalty/100·3.2` px |
| 纪律 `level` | 描边色 | 1 `#ffd166` / 2 `#ffa94d` / 3 `#ff6b5e` |
| 冷处理 `ignoreUntil` | 连线虚线 | `ignoreUntil > now` → `setLineDash([4,6])` |
| 最近互动 | 亮度 | `R = exp(-ageDays / stability)`，`stability = clamp(2 + love·0.16 + ln(1+count)·1.7 + score·0.02, 1.5, 90)` |
| 好感档位 | 节点大小 | 陌生 3.2 / 眼熟 4.2 / 熟人 5.2 / 好朋友 6.4 / 特别的人 8.0 |
| 群 `group` | 扇区角度 | 群按人数排序后均分圆周，群内按好感排开 |

`R(t)` 与 `memory-retention.js` 的 `retention()` 是同一个公式（`exp(-t/S)`），稳定度 S 改用关系数据推导。

## 想让画面变好看，调这几处

`src/relation-graph.js`
- `DIST_FAR / DIST_NEAR`：外层与内层的半径比例（现在 1.0 / 0.22）
- `BANDS[].size`：各档位的节点大小
- `distanceFor()` 里的指数 `0.85`：越小，中间档位越往外散
- `stabilityDays()`：亮度衰减快慢（现在 1.5~90 天）

`src/social-graph-view.js`
- `layout()` 里 `R=Math.min(W,H)*0.36`：整张图的半径
- `cy=H*0.46`：圆心上下位置
- `layout()` 里 `span`：同群扇形张角
- 绘制里的 `alpha`：连线透明度

## 人与人之间的连线（2026-11-01 追加）

口径（已确认）：**接话 + @提及合并计分，只画最强 15 条**。

| 信号 | 判定 | 权重 |
|---|---|---|
| 接话 | 同一群里 A 发言后 **5 分钟**内 B 发言，且中间没有 A 自己接着说 | 1 |
| @提及 | 正文出现 `@昵称`，且昵称能对上同群某个人 | 0.5 |

- 数据来源：`state/transcripts/group_*/**.jsonl` 近 **14 天**（只读，扫描结果缓存 5 分钟）
- 对称化：A→B 与 B→A 合并成一条无向边
- 排除：她自己（按 `selfUid` 与 `selfName`）、不同群、跨群消息不连
- 强度：`strength = weight / 最强一条`，用于线宽与透明度
- 她和谁最常聊：写进悬停卡片的「常聊」一行

调参位置：`src/relation-graph.js` 顶部常量

```
LINK_WINDOW_MS      = 5 * 60 * 1000   // 接话时间窗
LINK_REPLY_WEIGHT   = 1
LINK_MENTION_WEIGHT = 0.5
LINK_TOP_N          = 15
```

画面上的表现（`src/social-graph-view.js`）：
- 普通人际线：冷蓝、细、向外弯
- 与主人的往来：暖金、更细更淡，和「人到中心」的冷蓝直线区分
- 悬停/钉住某人：他的连线加亮、加粗、带辉光，其它线淡出

## 语义关系（她自己观察后写下的）

存储：`state/impressions.json` → `relations[fromUid] = [{ to, kind, note, at }]`

```
kind  只有三种：亲近 / 对立 / 依赖
from  关系的描述方（A 怎么看 B）
to    被描述的人
note  一句备注，最多 80 字
```

- 谁写：她自己，用 MCP 工具 `qq_relation`
  - 写：`from` + `to` + `kind` + 可选 `note`
  - 查：只传 `target`（看某人记下的关系）
- 接口：`GET/POST /api/socialV2/relation`（需 `key`；令牌规则同其它 socialV2 接口）
- 开关：`config.json` → `socialV2.tools.relation`（默认开）
- 每人最多 30 条，同一对重复写会覆盖旧的

合并规则（`buildSemanticEdges`）：
- 只保留两端都在图里的人（她本人与陌生人剔除）
- 同一对人两个方向都有记录 → 合并成一条，`mutual=true`
- kind 冲突时按 **对立 > 依赖 > 亲近** 取代表

画面表现：
- 亲近：暖白实线
- 对立：琥珀虚线
- 依赖：冷白点线 + 箭头（指向被依赖的人）
- 悬停某人时，他相关的语义关系加亮

**注意**：`qq_relation` 是新加的 MCP 工具，已经开着的 DSH 会话不会热加载，要等她下一次换会话（或重启 DSH）才出现在工具列表里。

## 隐私

- 列表与悬停：QQ 号打码（`maskUid`，前 4 + `****` + 后 2）
- 只有**点击钉住**后才显示完整 QQ 号
- 印象文字默认折叠，点「展开印象」才显示
- 接口只返回白名单字段，不含 token / 消息正文 / 唤醒配置

## 已知限制

- `love` 字段目前全空（只有主人有 `loyalty=100`），所以除了主人几乎看不到暖色与粗线；等真实喜爱数据积累后会自动变。
- 好感分目前大部分是 0，所以节点挤在外圈同一半径上，视觉上是一圈「陌生」。
- 不做「人与人之间」的连线（现有数据里没有人物之间的关系）。
