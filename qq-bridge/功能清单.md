# qq-bridge 功能清单与运行状态

> 运行状态不写死在这里——双击桌面「qq-bridge状态」，会重新生成 `状态报告.txt`（端口、进程、角色、记忆、余额、最近自检）。

## 一、运行与自愈

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 全链路 | QQ → SnowLuma → 桥接 → DSH → DeepSeek 模型 | ✅ |
| 开机自启 | 登录后隐藏启动 QQ、DSH、SnowLuma、桥接、看门狗 | ✅ |
| 一键启动 | 桌面「一键开启QQ对接」，10~40 秒恢复 | ✅ |
| 看门狗 | 每 10 分钟自检，缺谁补谁，端口自动对齐 | ✅ |
| 自动注入 | SnowLuma 发现 QQ 自动注入，不用手点「加载」 | ✅ |

## 二、聊天与互动

- 群聊 / 私聊；白名单 + 黑名单；管理员识别
- 自主决定回不回、什么时候潜水、什么时候主动开话题
- 表情包：收藏 20 张，能发、能看、会自己偷图、会给图记备注
- 拍一拍：被拍回拍、主动戳熟人
- 合并转发：展开看里面的文字和图片
- 引用回复、@ 点名、分条发送
- 图片/表情识别（多模态）
- 群文件：列表 + 读取（文本正文、图片进视觉，超过 8MB 拒绝）

## 三、记忆与时间

| 功能 | 说明 |
| --- | --- |
| 三层记忆 | 核心（永久）/ 长期（永久）/ 短期（3 天过期），跨群共享 |
| 开局注入 | 新会话第一次醒来自动带核心/长期记忆 |
| 日期标签 | 每条记忆带 [今天/昨天/N天前] |
| 时间感知 | 每次唤醒有【时间】+ 距上条消息多久 |
| 每日整理 | 凌晨 4 点，或开机后补做 |
| 自主换会话 | 上下文到 80% 提醒她写摘要、换新会话 |

## 四、情感与关系

- 好感度：每人一份，每条消息 +0.8，久不聊会降；陌生/眼熟/熟人/好朋友/特别的人
- 主人锁满 100，永不衰减；私聊可叫「老大」「爸爸」
- 心情：开心/生气/吃醋/难过/好奇/骄傲/平静/委屈/得意/害羞，2 小时回落
- 外号唤醒：DeepSeek、小鲸鱼、鲸鱼、大肥鱼等出现就叫醒她
- 外号反应：受用的开心，叫「大肥鱼」怼回去

## 五、外部能力

- 联网搜索（DeepSeek 优先）+ 网页正文抓取（防 SSRF）
- 余额查询（官方接口），低于 ¥5 私聊提醒加饭

## 六、安全边界

不能操作电脑、读写文件、执行命令、发空间动态、加好友/踢人、上传/删除群文件。群里任何人都无法通过聊天让她碰你的电脑。

## 七、运维

- 控制台 `http://127.0.0.1:3100`（白名单、人格、模式、token 花费）
- 日志：`state\bridge.log`、`run-out.log`、`watchdog.log`、`autostart.log`
- 状态：双击桌面「AI运行面板」→ 浏览器打开 `http://127.0.0.1:3100/dashboard`（实时、30 秒自动刷新）
