# 灵犀 QQ 桥接（dsh-qq-bridge）

把 `qq-bridge` 的控制台搬进 DSH 的设置里：状态、白名单、角色、重启、测试发送、日志、
黑话、表情、提示词、刷B站日报、社交状态。

**两个可视化页面保留**：`/dashboard`（总控制可视化面板，操作卡里「打开可视化面板」直接进）
和 `/memory`（记忆星图）。只有旧控制台 `/panel` 停用了（404）。

## 装在哪儿

插件目录：`%USERPROFILE%\.dsh\plugins\dsh-qq-bridge`

它需要能和 `qq-bridge` 说上话。桥接的位置按这个顺序找：

1. 环境变量 `DSH_QQ_BRIDGE_ROOT`
2. `%USERPROFILE%\.dsh\qq-bridge-path.json` 里的 `path`（安装器会写）
3. 常见位置：`D:\DSH\qq-bridge`、`C:\DSH\qq-bridge`、`E:\DSH\qq-bridge`、`%USERPROFILE%\qq-bridge`…

## 拓展

别的插件要往这一页加卡片、或者本机脚本要读写桥接数据，看
[docs/EXTENDING.md](docs/EXTENDING.md)：

- **卡片扩展槽** `settings.qq-bridge.card` —— DSH 原生子槽位，`ctx.slots.inject` 注册
- **HTTP 接口** `GET /dsh-qq-bridge/api` —— 服务器上的清单，永远和真实注册表一致
- **邻接插件** `GET /dsh-qq-bridge/peer` —— 这台机器上还装着哪些带界面的插件（中文名读 `dshLabel`）

### 已经接上来的是「星图开机」

`dsh-star-boot`（1.9.0 起）是扩展槽的第一个真实使用者，两条线各走一边：

```
星图开机 → 灵犀   片头设置卡插进「系统」标签最下面：片头模式 / 背景 / 此屏会显示什么 /
                  四盏灯 / 预览片头 / 打开片头设置
灵犀 → 星图开机   开机片头的状态卡多一格「链路」：DSH · SnowLuma · OneBot · QQ 四盏灯
                  （宿主直接问 3100/diag，不依赖本插件先起来）
```

两边都**只认槽位名和接口**，不认识对方的代码：灵犀没装，星图照常开机；星图没装，这一页跟以前一样。

## 安全

- 写接口要求同源：跨站 POST 一律 403。
- 插件自己读 `state/console-token`，用户不用交 token。
- 改 `config.json` 前先备份成 `config.json.bak-settings-<时间>`，写入是临时文件 + rename。

## 发补丁

这个插件自己会「检查更新」。**默认没有更新源**——第一次要在设置页里填一次
「用户名/仓库名」（存在 `~\.dsh\dsh-qq-bridge-update.json`）。

发版流程（tag 前缀、补丁包结构、回滚）写在
[docs/UPDATING.md](docs/UPDATING.md)，打包用 `打补丁包.ps1`。

## 第一次打开

桥接程序还没放好时，这一页只显示**新手引导 + 运行状态**，其余面板收起来——
不然新用户看到的是一屏「找不到 config.json」。程序放好、页面轮询看到之后会自动展开，不用刷新。

## 重启 DSH 之后桥接会自己回来

桥接盯着 DSH 的事件流，DSH 一退它就跟着退（这是桥接自己的设计）。
插件的宿主那一半**每次加载都会摸一眼 3100**，没在跑就在 5 秒后后台拉起（先对齐新端口）。
不想要这个行为：设置里把「DSH 启动时自动拉起桥接」关掉，或在 `config.json` 写 `"autoStartBridge": false`。

开机自启默认**不装**：桥接没有 DSH 就没用，装了只会在 DSH 没开时反复起一个立刻退出的进程。
想要随开机启动，用安装器的 `-Autostart`。

## 页面长什么样

顶部是名牌（名字 + 状态胶囊），下面五个分页，切走再回来输入不丢：

```
总览   新手引导 / 运行状态 / 操作（自定义测试消息、试听语音、复制诊断）
连接   谁能跟她说话 / 运行设置
灵魂   人格卡 / 黑话 / 表情 / 提示词
记忆   记忆星图 / 她的本子 / 刷B站日报
系统   检查更新 / 备份 / 日志 / 扩展卡片
```

现在加载时会看一眼 `config.json` 里那个端口还在不在，死了就自动重新对齐一次。
新增 `test/realign.mjs` 9 项守这条。
