# dsh-qq-bridge · 把 QQ 接进 DeepSeek Harness

> 仓库叫 **DSH-QQ**，插件包名 **`dsh-qq-bridge`**，桥接本体叫 **qq-bridge**。

一句话：**让你的 DSH 住进 QQ 群和私聊。** 有人格、有跨会话记忆、会学群里的黑话、会发表情包、会发语音，还会自己判断什么时候该说话、什么时候该潜水。

> 界面与交互由 **Claude Opus 5.5** 重新设计打磨 —— 名牌、五段式标签、动效、状态胶囊，全是它操刀。强得有点离谱。

---

## 这是什么

一套把「QQ ↔ SnowLuma ↔ qq-bridge ↔ DSH」串起来的完整方案，分三块：

| 组件 | 作用 |
|---|---|
| **qq-bridge** | 桥接本体：收 QQ 消息、组上下文、调 DSH、把回复发回 QQ |
| **dsh-qq-bridge** | 设置页插件：把整个控制台搬进 DSH → 设置 → QQ 桥接（**没有第二个网页**） |
| **qq-agent-presets / qq-mode-console** | QQ 聊天专用的 agent 预设 + 模式切换 |

## 能做什么

**聊天**
- 私聊、群聊，只回白名单里的人；@ 或点名必回
- 二代会自己决定先看谁、回谁、发几条；一代按概率接话
- 没人说话时会主动起话题（可关）

**人格与记忆**
- 人格卡（role）随时切换、在线编辑，保存前自动备份
- 跨会话长期记忆，能画成「记忆星图」——每个点是一条记忆，可全屏看
- 事件备忘录、对每个人的印象、好感度，全是桥接自己的数据

**表达**
- 收藏表情包，也能「偷」别人发的图
- 语音：GPT-SoVITS 本地音色 / Edge TTS 在线，7 种中文音色
- 黑话：群里出现新词会自己学（10 条消息起触发）
- 刷B站：每天把刷到的视频带进上下文，出日报

**好好干活的部分**
- **一键对接**：自动找到 DSH 当前端口、按命令行杀掉旧桥接、等端口释放、重启、用 `/diag` 自检
- **DSH 启动自动拉起桥接**（可关），不用每次手动点
- **备份**：配置 / 人格卡 / 提示词的历史版本，一键还原
- **诊断**：版本、路径、四灯、最近日志，一段文本直接复制给人看
- **日志**：200 行、关键词过滤、自动刷新、一键打开文件夹
- **检查更新 + 一键打补丁**：本仓库的 release 就是更新源

## 界面

DSH → 设置 → QQ 桥接，五个标签，切走再回来输入不丢：

```
总览   新手引导 / 运行状态 / 操作（测试发送、语音试听、复制诊断）
连接   谁能跟她说话 / 运行设置（11 个开关、9 个数值、音色）
灵魂   人格卡 / 黑话 / 表情 / 提示词
记忆   记忆星图 / 她的本子 / 刷B站日报
系统   检查更新 / 备份 / 日志 / 扩展卡片
```

第一次打开只有「新手引导 + 运行状态」，桥接没装好时不会给你一屏报错；装好后自动展开。

## 安装

**你需要自备：** DSH（DeepSeek Harness）、SnowLuma（QQ 网关，第三方）、一个 QQ 号。

> **SnowLuma 怎么装？** 它不在本包里（第三方项目，有自己的许可）。下载、扫码、OneBot 端口、常见问题都写在
> **[docs/SNOWLUMA.md](docs/SNOWLUMA.md)**。装完回到 DSH 点「重新检测」就行。

1. 到 [Releases](https://github.com/2524034412-boop/DSH-QQ/releases) 下载 `qq-bridge-installer-2.2-public.zip`
2. 解压到任意位置，双击 **安装.cmd**
3. 打开 DSH → 设置 → QQ 桥接，按「新手引导」走：
   - 装 SnowLuma：**先登录官方 QQ**（手机 QQ 扫码），再让 SnowLuma 接入 QQ 进程
     —— 具体看 [docs/SNOWLUMA.md](docs/SNOWLUMA.md)
   - 填管理员 QQ
   - 加一个群或自己的私聊
4. 点「发一条测试消息」，QQ 收到就通了

**这个公开版不含任何个人数据**：没有作者的配置、人格卡正文和语音样本。首次启动会按 `config.example.json` 生成一份空白配置，人格卡给的是 `roles/示例人格.md`（自己改）。

## 更新

设置 → QQ 桥接 → **系统** → 检查更新。
仓库已经内置成更新源，以后发新版本点一下就装（只更新设置页插件，不碰桥接本体和你的数据）。

## 常见问题

- **桥接没在跑** → 总览点「重启桥接」；点完还红就看「系统 → 日志」
- **一键对接没反应** → 现在会先杀旧桥接再起新的；如果还失败，把「复制诊断信息」的内容发到群里
- **没有声音** → TTS 没配；最快是用 Edge TTS（不需要本地模型）
- **她谁也不回** → 白名单是空的：至少加一个群或一个私聊
- **界面没出现** → 重启一次 DSH
