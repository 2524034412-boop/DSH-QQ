## 装它、让它连上 QQ

> **先搞清楚一件事**：SnowLuma 自己**不**做扫码登录。
> 它是 QQ 客户端的互操作运行时 —— 先让**官方 QQ** 登录好，再让 SnowLuma 接上那个 QQ 进程。
> 所以二维码出现在 **QQ 客户端**里，不在 SnowLuma 的网页上。

1. 从 Releases 下载 Windows x64 完整包，解压到任意目录（比如 `D:\snowlunar`）
2. **先登录官方 QQ**：打开 `QQ.exe`，没登录就用手机 QQ 扫码登录，保持 QQ 开着
3. 双击 SnowLuma 的 **`launcher.bat`** 启动
4. 浏览器打开 **http://localhost:5099**
   - 初始密码在启动日志里（控制台窗口里那几行）
5. 在 WebUI 里**接入 QQ 进程**：按页面引导加载刚登录好的那个 QQ
   - 之后如果显示未就绪，点进程行上的「刷新 / 重连」重查一次
6. 配置 **OneBot 连接**，保持默认端口：

   | 类型 | 端口 | 说明 |
   |---|---|---|
   | HTTP 服务端 | `3000` | 桥接用它发消息 |
   | WebSocket 服务端 | `3001` | 桥接用它收消息 |

   桥接启动时会自己读一次 WS 令牌（日志里那句「自愈完成」），一般不用手填。

7. 回到 **DSH → 设置 → QQ 桥接 → 新手引导**，点「重新检测」。
   「SnowLuma」和「QQ 连上了吗」两项应该变绿。

## 常见问题

**5099 打不开**
`launcher.bat` 没跑起来，或者被防火墙拦了。看控制台窗口有没有报错。

**扫码后 QQ 没反应**
先确认 QQ 客户端真的登录成功了（不是卡在扫码页）；再在 SnowLuma WebUI 里找到 QQ 那一行，点「刷新 / 重连」，回 DSH 重新检测。

**3000 / 3001 没人听**
WebUI → 连接配置 → 启用 OneBot 的 HTTP 和 WebSocket **服务端**（不是客户端）。

**端口想改**
桥接默认认 3000/3001。别改；确实要改，先把桥接的 `config.json` 里 `snowluma.httpUrl` / `wsUrl` 一起改掉。

**初始密码忘了**
看启动日志；不行就重装一份，账号数据在它自己的目录里。

**要不要开「记住我」**
要。不然每次开机都要重扫码，桥接会一直重连。
